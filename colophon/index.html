Colophon

hellojames is a continuous work in progress, built in the open. Static HTML and CSS, and a bit of progressive enhancement. Proudly brutalist. The indie web lives.

Typesetting is Georgia 24px/1.6 and Anonymous Pro 12px/1.6, via Google Fonts.

It's made with Sublime Text and Firefox, and runs on Jekyll and GitHub Pages.
