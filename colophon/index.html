Colophon

hellojames is a continuous work in progress, built in the open.

It's made with Sublime Text and Firefox, and runs on Jekyll and GitHub Pages.
Static HTML, vanilla CSS, no javascript and no cookies.
Typesetting is Georgia 24px/1.6 and Anonymous Pro 12px/1.6.
Proudly brutalist. The indie web lives.
